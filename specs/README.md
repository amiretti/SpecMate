# Specs

Una carpeta por historia grande o SDD (ADR-0027): `specs/<###>-<slug>/feature.md` en la
ruta grande, o los artefactos de Spec Kit (preset `workspace-sdd`) en la ruta SDD.

## Fases y dependencias

E0 Spike → E1 Plantilla segura del sitio → E2 Relevamiento guiado y brief verificable →
E4 Biblioteca de secciones y construcción → E3 Opciones combinables y elección →
E5 Verificación y publicación → E6 Tres clientes reales (ADR-0029 a ADR-0032).
E3 va después de E4 porque las opciones se arman con la biblioteca de secciones.
Detalle en los issues de cada épica.
